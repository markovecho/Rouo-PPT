# Rouo PPT · 简短介绍 / Short Intro

## 中文

Rouo PPT 是给 AI 智能体的演示文稿工作室：五族风格（电子 / 极简 / 水彩 / 编辑 / 蓝图）乘三条产线。手作线逐页手写 SVG，出原生可编辑 PPTX；量产线用 COM 直驱 WPS 或 PowerPoint，可见地逐页生成；网页线是单文件 HTML，带动态背景、演讲者模式、观众屏同步。

动笔前必问风格、主题色与交付格式。文字形状表格图表公式全是原生对象，双击即改；只用真实品牌资产，取不到就诚实降级；颜色从内容推导，不凭空发明。整套 34 份文档、10 个脚本与完整性守卫。

## English

Rouo PPT is a presentation studio for AI agents: five style families — Electronic, Minimal, Watercolor, Editorial, Blueprint — crossed with three production lines. The handcrafted line writes SVG page by page, exports native editable PPTX. The mass line turns data into page JSON, driving WPS or PowerPoint over COM, slide by slide. The web line is one HTML file with WebGL backgrounds, presenter mode, and audience-screen sync.

It always asks three questions first: which family, which theme color, which delivery format. Text, shapes, tables, charts and formulas stay native — double-click and edit. Only real brand assets are allowed; when one can't be fetched, it degrades honestly. Colors come from brand and content, never invented. The bundle: 34 documents, 10 scripts, and a fail-closed integrity guard.
