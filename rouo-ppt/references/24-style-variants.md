# 风格族 4 · 编辑风 —— 风格族 5 · 蓝图风

> 两个备选体系。当电子风的"杂志感"或极简风的"瑞士感"都不贴内容时，从这两个里挑。

---

# 风格族 4 · 编辑风 `editorial`

> 美学锚点：旧版《国家地理》+ 企鹅书封 + 精装书内页。
> **这是"电子墨水"被推到极致的结果** —— 抽掉 WebGL、抽掉彩色，只剩纸、墨、和排印本身。

## 一 · 它和电子风的区别

电子风是"杂志 + 代码"（有动态背景、有彩色主题、有 WebGL）；
编辑风是"**一本书**"——**没有动态、没有彩色、没有装饰**，一切靠排印层级。

| | 电子风 | 编辑风 |
|---|---|---|
| 背景 | WebGL 流体（hero 页透出） | **纯纸纹，无任何动态** |
| 色彩 | 5 套带色主题 | **只有纸与墨，最多一个暖色点缀** |
| 信息密度 | 低（每页一个论点） | **高（可以放整段论述）** |
| 主角 | 大标题 + 大留白 | **正文本身** |
| 特有元素 | stat / pipeline / ghost 字 | **首字下沉 / 边注 / 脚注 / 栏线** |

## 二 · 三套纸墨关系（不是配色，是材质）

| # | 名称 | 纸 | 墨 | 点缀 | 适合 |
|---|---|---|---|---|---|
| 1 | 📄 **冷白书纸** | `#f7f7f5` | `#141413` | 无 | 学术 / 商业 / 通识 |
| 2 | 📜 **米黄书纸** | `#f2ebdc` | `#2b241c` | `#8a6a3f` 熟褐 | 历史 / 文学 / 人文 |
| 3 | 🗞 **报纸灰** | `#eae7e1` | `#1c1c1a` | `#7a3b2e` 砖红 | 时事 / 评论 / 行业观察 |

**规则**：点缀色**整份 deck 出现不超过 5 次**，且只用于：章节序号、关键引语的竖线、一处数据强调。

## 三 · 排印要素（编辑风的全部家当）

| 要素 | 规格 | 用法 |
|---|---|---|
| **首字下沉** | 首字 = 3 行高，`float:left`，`margin-right .4em` | 每章开篇第一段 |
| **栏线** | 1px `rgba(ink,.18)`，**只在多栏之间** | 不要给段落加框 |
| **边注** | 外侧 1/6 宽度，字号 .75em，`opacity .6` | 补充事实、来源、术语 |
| **脚注** | 正文上方 1px 短线 + `.72em` 字号 | 引用与出处 |
| **小型大写** | 章节标签、栏目标题 | `font-variant:small-caps` 或手写大写 |
| **首行不缩进** | 段落之间用空行分隔，不用缩进 | 现代书排印习惯 |
| **页码装饰** | `.72em` 等宽 + 两侧短横线 | 页脚：`— 23 —` |

**字体**：Noto Serif SC（中文正文与标题，字重 300–500）+ Georgia（拉丁）。
**不要**无衬线大标题 —— 那会把它变成普通的商务 PPT。

## 四 · 版式（六种）

| 版式 | 结构 | 用途 |
|---|---|---|
| E1 书名页 | 居中书名 + 副题 + 出版感信息条 | 封面 |
| E2 单栏论述 | 单栏正文 + 首字下沉 + 边注 | 深度段落 |
| E3 双栏对读 | 左右两栏等宽 + 中央栏线 | 对照 / 双语 / 论辩 |
| E4 图文插页 | 满版图片 + 下方细排 caption | 纪实照片 |
| E5 引语页 | 3–5 行引语 + 出处 + 大量留白 | 章节过渡 |
| E6 目录页 | 两栏条目 + 前导点（`……`）+ 页码 | 长文导航 |

## 五 · 硬规则

- 每页**正文不少于 80 字**（编辑风的"密度"是它的身份；一页只有两行字就选错风格了）
- 字号下限：正文 **≥ 17px**、边注/脚注 **≥ 13px**
- 行高 **1.7–1.85**（比电子风松，长文才读得下去）
- 每行中文 **≤ 38 字**（超过就要分栏）
- **不许出现**：阴影 / 圆角 / 彩色卡片 / 图标装饰 / 大字号 hero / 动效（除段落淡入）
- 图片**只做满版或半版**，不裁成小卡片
- 整份 deck **每页都是静态的** —— 编辑风的庄重感来自"不动"

## 六 · 能力边界

| 交付 | 支持 | 说明 |
|---|---|---|
| 网页 deck | ✅ | 但要**关掉 WebGL 背景与大部分动效**，只留段落淡入 |
| 原生 PPTX | ✅ **很适合** | 排印转 PPTX 损失小，长文本可编辑是刚需场景 |
| 长文承载 | ✅ **最强** | 五族里唯一能舒适承载整段论述的 |
| 数据可视化 | ❌ | 图表要锐利，编辑风偏软。数据页换极简风 |

# 风格族 5 · 蓝图风 `blueprint`

> 美学锚点：建筑蓝图 + 电路原理图 + 机械制图。
> **用工程制图的语法讲产品、架构、系统关系。**

## 一 · 两套制图底

| # | 名称 | 底 | 线 | 网格 | 适合 |
|---|---|---|---|---|---|
| 1 | 🔷 **蓝底蓝图** | `#0e3a5c` | `#dff0ff` | `rgba(223,240,255,.10)` | 技术发布 / 架构宣讲 / 暗场投屏 |
| 2 | ⬜ **白底蓝图** | `#f4f6f7` | `#1b4965` | `rgba(27,73,101,.10)` | 教学 / 文档 / 需要打印或批注 |

**只有这两套，不要发明第三套。** 蓝图风的美感来自"这就是制图"，不是配色创意。

## 二 · 制图语法（本风格的灵魂）

| 元素 | 规格 | 说明 |
|---|---|---|
| **坐标网格** | 主格 48px、次格 12px，`opacity .10` | 满版铺底，永不出现在文字下方太密处 |
| **标注引线** | 1px 折线（先水平再斜 45°），末端 3px 实心圆点 | 从元素引到注记，**这就是蓝图风的签名动作** |
| **尺寸线** | 两端带短竖挡的细线 + 中间标注 | 表达"多长 / 多大 / 多少" |
| **编号节点** | 圆或方框 + 编号（`01` `02`） | 与图例对应 |
| **图例** | 右下或左下，2–4 项，符号 + 文字 | 有编号节点就必须有图例 |
| **视口括角** | 四角 L 形短括 | 标记"这是主视图区" |
| **注记** | 等宽字，全大写英文混中文 | `NODE 03 · 鉴权服务` |

**字体**：等宽为主（Consolas，注记 / 编号 / 图例）+ Noto Sans SC 细体 300–400（说明文字）。
**不要**衬线 —— 制图不抒情。

## 三 · 版式（五种）

| 版式 | 结构 | 用途 |
|---|---|---|
| B1 总图页 | 满版系统图 + 角落图例 + 视口括角 | 架构总览 / 生态地图 |
| B2 分解页 | 左侧分解图 + 右侧编号说明列表 | 组件拆解 |
| B3 步骤页 | 水平流程 + 尺寸线标"耗时/成本" | 实施路径 |
| B4 规格页 | 表格化参数 + 尺寸线标注 | 产品规格 / benchmark |
| B5 剖切页 | 大图放大局部 + 引线注记 | 细节原理 |

## 四 · 硬规则

- **所有连接走直角或 45° 折线，不走贝塞尔曲线**（圆滑曲线是蓝图风的违规）
- 线条粗细只有 **两档**：`1px`（一般）+ `1.5px`（主结构）。**不要三档以上**
- 引线**不许交叉**，必须交叉时用"跳线小拱"
- **图例符号与图中节点一一对应**，不能有没解释的符号
- 文字最小 **14px**（等宽注记）；说明正文 **≥ 16px**
- **不许出现**：阴影 / 圆角 / 渐变 / 彩色装饰 / 照片（照片若要出现必须去色 + 叠网格）
- 白底蓝图**打印友好**，蓝底蓝图**投屏友好** —— 按最终用途选

## 五 · 能力边界

| 交付 | 支持 | 说明 |
|---|---|---|
| 网页 deck | ✅ | 网格与引线用 SVG 画，清晰；不要 WebGL |
| 原生 PPTX | ✅ **很适合** | 全是直线、矩形、等宽字 —— **原生形状与文本框还原度最高的一族** |
| 系统关系 / 架构 | ✅ **最强** | 五族里唯一把"关系"当主角的 |
| 情感型内容 | ❌ | 讲故事、打动人不是它的活 |

# 五族对照总表

| | 电子风 | 极简风 | 水彩风 | 编辑风 | 蓝图风 |
|---|---|---|---|---|---|
| **锚点** | Monocle + 代码 | Vignelli / Helvetica | 手稿本 / 图鉴 | 书 / 报纸 | 蓝图 / 制图 |
| **字体** | 衬线+无衬线+等宽三分 | 全程无衬线 | 衬线 ≤500 字重 | 衬线为主 | 等宽为主 |
| **色彩** | 5 套带色主题 | 4 套单 accent | 5 套颜料（≤2/页） | 纸墨 + 一点缀 | 2 套制图底 |
| **骨架** | 10 式 | 22 式（锁定） | 5 式 | 6 式 | 5 式 |
| **信息密度** | 低 | 中 | 低 | **高** | 中高 |
| **签名动作** | hero 页 WebGL 透出 | 极致字号对比 | 毛边与颜料沉积 | 首字下沉 + 边注 | 引线 + 尺寸线 |
| **网页 deck** | ✅ 原生 | ✅ 原生 | ✅ 推荐 | ✅ 需关动效 | ✅ |
| **原生 PPTX** | ⚠️ 降级 | ✅ 好 | ✅ 需烘图 | ✅ 好 | ✅ **最好** |
| **量产线 COM** | ❌ | ✅ | ❌ | ⚠️ 薄弱 | ✅ |
| **最擅长** | 杂志感分享 | 数据与信息图 | 情感与人文 | 长篇论述 | 关系与结构 |

## 组合禁忌（硬规则）

- ❌ **五族之间不混搭** —— 极简风的直角纯色卡 + 水彩风的晕染底会互相拆台
- ❌ **一份 deck 不换风格** —— 从封面到尾声同属一族
- ❌ **两族各占一半页** —— 观众会以为拼错了文件
- ⚠️ **实在有跨段需求**：做**两份** deck，或全篇选一族、把对照页做成"另一族的引用卡"（明确标注这是外部资料）

**要换风格，是新做一份，不是改几页。**
