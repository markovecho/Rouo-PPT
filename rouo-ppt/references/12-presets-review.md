## 一 · 四套设计预设

按 deck 类型选一套作为起点（用户品牌资产优先于任何预设）：

### 1. `academic` 学术答辩
- **色**：主深蓝 `(26,60,139)` / 辅橙 `(230,119,51)` / 点缀绿 `(24,128,80)` / 正文 `(34,34,34)` / 浅底 `(245,248,252)`
- **字**：标题 Arial 40pt 深蓝粗体；正文 24pt；标注 16pt；中文微软雅黑 24pt
- **间距**：边距 80 / 间隔 24 / 行高 1.5
- **规则**：视觉内容占 60–70% · ≤5 色 · 色盲友好 · 一页一主题 · 留白 40–50% · 要点 ≤6

### 2. `consultant` 咨询顾问
- **色**：主深蓝 `(0,51,102)` / 辅亮青 `(0,168,232)` / 点缀橙 `(255,140,0)` / 浅底 `(242,246,250)`
- **字**：标题 36pt；正文 18pt
- **规则**：视觉占 50% · ≤4 色 · 网格布局 · 内容密度中等 · 要点 ≤5

### 3. `business` 商务汇报
- **色**：主商务蓝 `(0,82,148)` / 强调红 `(200,40,40)` / 点缀绿 `(45,160,80)`
- **字**：标题 36pt；正文 18pt
- **规则**：视觉占 45% · ≤4 色 · 要点 ≤6 · 密度中等

### 4. `tech` 科技极简
- **色**：**暗色模式**——底近黑 `(15,20,35)` / 辅亮青 `(0,200,255)` / 点缀橙红 `(255,100,60)`；浅色文字
- **字**：标题 44pt 白；正文 20pt 白
- **规则**：视觉占 55% · ≤3 色 · 色盲友好 · 留白 50% · 要点 ≤4 · 密度低

## 二 · 版式库（14 种布局模板）

每页按内容族选一种版式，元素坐标遵循 `11-deck-data-format.md` 的坐标系：

| 版式 | 类别 | 结构 |
|---|---|---|
| `cover` 封面 | 封面 | 品牌色顶底条 + 72pt 大字标题 + 装饰线 + 副标题/日期 |
| `toc` 目录 | 内容 | 编号方块 + 标题 + 副标题，6–8 项导航 |
| `overview` 概览 | 内容 | 顶部横幅标题 + 信息卡矩阵 + 侧边荣誉栏 |
| `timeline` 时间轴 | 栏式 | 圆点+竖线+事件，适合历史/发展 |
| `grid_cards` 卡片网格 | 网格 | 2–4 列卡片，适合多人物/多地标/多产品 |
| `quadrant` 四象限 | 网格 | 2×2 对比布局，适合分类 |
| `stats` 数字统计 | 内容 | 6 个数字卡 + 底部说明 |
| `three_col` 三列对比 | 栏式 | 三列并排，适合三方案/三时期/三角度 |
| `pipeline` 流程图 | 内容 | 水平管道流程 + 彩色模块 + 连接 |
| `data_table` 数据表格 | 内容 | 左表格 + 右解读 |
| `content_image` 图文 | 图片 | 左文右图 / 左图右文 |
| `closing` 结语 | 封底 | 品牌色满版 + 总结 + 联系方式/格言 |
| `chart_page` 图表页 | 内容 | 标题 + 大图表 + 要点行 |
| `quote` 引语页 | 内容 | 大引号 + 引文 + 出处 |

**典型页面结构参考**（12 页 deck）：封面 → 目录 → 概览 → 时间轴 → 四象限 → 卡片网格 → 数字统计 → 流程图 → 数据表格 → 图文 → 三列对比 → 结语。

## 三 · 叙事弧与谈话预设

内容组织遵循 **钩子 → 背景 → 问题 → 方法 → 结果 → 启示 → 收束** 的叙事弧：

| 谈话类型 | 页数 | 版式序列要点 | 关键规则 |
|---|---|---|---|
| 学术会议 | 12–20 | cover→toc→overview→timeline→quadrant→…→stats→closing | 视觉占 65%，关键发现 ≤2 个 |
| 商务汇报 | ≤15 | cover→toc→overview→stats→three_col→pipeline→…→closing | 视觉占 50% |
| 论文答辩 | 45–65 | 全版式轮换，timeline/quadrant/stats 承载数据 | 视觉占 60% |
| 机构/学校介绍 | ≤14 | cover→toc→overview→timeline→three_col→grid→stats→closing | 视觉占 55% |

## 四 · 单页五维质检

对每页（或每张幻灯片的元素清单）执行检查，按维度扣分，满分 100，**<70 不通过**：

### 机器可算的检查（元素清单级）

| 检查 | 规则 | 扣分 |
|---|---|---|
| 字号 | 标题 <36pt、正文 <20pt（投屏基准）、标注 <14pt | −5 / −3 / −2 |
| 密度 | 文本块数 > 预设要点上限 × 1.5 | −10 |
| 视觉占比 | 非文字元素占比 < 预设目标 − 0.2 | −5 |
| 一页一主题 | 标题角色元素 > 1 个 | −10 |

### 五维审查（人工/agent 目视，各维度有阈值）

| 维度 | 检查项 | 阈值 |
|---|---|---|
| **视觉** | 字体层级 · 颜色对比 · 留白比例 · 布局一致性 · 图片质量 | 70 |
| **叙事** | 叙事弧完整 · 预备知识清晰 · 示例充分 · 符号一致 · 逻辑流畅 | 75 |
| **校对** | 拼写 · 语法 · 术语一致 · 标点 · 字体溢出 | 80 |
| **一致性** | PPTX vs PDF 一致 · 字体嵌入 · 图片不丢 · 动画兼容 | 85 |
| **实质** | 数据准确 · 引用完整 · 结论有支撑 · 方法可复现 | 90 |

**整 deck 评审**：逐页打分取均值 + 警告计数，输出 `整体 X 分 / N 页 / M 个警告`。

### 质检通过后的目视清单

- [ ] 标题颜色统一、无装饰线
- [ ] 图文间距 ≥24pt，内容不贴标题
- [ ] 表格单行不换行，行高 ≥28pt
- [ ] 大数字与标签无重叠（三段式）
- [ ] 背景底图未被元素遮挡
- [ ] 每页 ≤80 字 + ≥2 种视觉元素
- [ ] 深浅两版 logo 各就各位（如有）

## 五 · 预设与品牌的关系

**用户品牌资产 > 任何预设**。预设是「没有品牌约束时的起点」，不是替代品：
- 用户给了品牌色 → 预设让位，布局规则保留
- 预设的色彩是示例锚点，走 `04-style-armory.md` 的色彩推导协议
- 预设的字号/密度/留白规则是底线，不因预设放松反平庸守则（`06-taste-rules.md`）
