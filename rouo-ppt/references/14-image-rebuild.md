# 图片重建 · 位图页帧 → 可编辑 PPTX

> 用户提供**位图视觉**（已批准的 mockup、导出的幻灯片、拼版 contact sheet、拍平的页面），要求还原成可编辑 PPTX 时走本路线。
> 照片/插画/情绪板作为**新故事素材**时不触发。

---

## 硬规则

1. **走快道**（`02-express.md`）：不用立约/确认门；主 agent 自己决定重建方案、手写 SVG、过快道质检、导出。
2. **是「源页面」不是「套模板」**：留在快道自由设计；**绝不**套用 Brand/Style/Layout 模板——会和源页面几何打架。
3. **最终 deck 保持 `pptx_structure.mode: flat`**：像素**不能**证明 Master/Layout 身份、占位符、主题血缘、隐藏对象——**绝不推断它们**。
4. **禁止「截图皮」**：绝不能把整张源页当唯一满版底图、上面盖一点可编辑文字。源页面是**比对证据**，不是底衬。

---

## 一 · 路由边界

| 请求形态 | 行为 |
|---|---|
| 图片就是「必须变成最终可编辑 PPTX」的页面 | 本路线 + 快道 |
| 一个文件多个清晰分隔的页帧 | 先切成**有序页面清单**再逐帧重建 |
| 图片只是新 deck 的普通素材/灵感 | 普通生成路线 |
| 图片要定义可复用工作区 | `15-template-system.md` |

---

## 二 · 把源图归一为页面

🚧 **GATE**：在任何分层决策或 SVG 编写前，必须有**有序的规范页面图清单**。

| 源形态 | 归一方式 |
|---|---|
| 一文件一完整页 | 一张规范页面图 |
| 多文件各一页 | 保留显式顺序或文件名自然顺序 |
| 规则拼版 | 按行优先切网格（不去 alpha） |
| 一文件多张非网格页帧 | 记录每张可见边界 bbox，无损裁成独立页 |

- 原件归档到 `sources/`；**绝不复写原件**
- **一帧 = 一页**：页数由帧数决定（不是文件数）；混合宽高比**阻塞**
- 边界或顺序不明 → 清单标记阻塞；**绝不静默合并/丢弃/重排**
- 每张规范页检查一次：文字、源图形、区域、重叠、边界完整性、遮挡

---

## 三 · 按内容族重建

按「它是什么」分类，不按「好不好裁」：

| 内容族 | 实现 | 不可越界的底线 |
|---|---|---|
| 可编辑文字 | 原生文字 | 逐字一致、行分组、对齐；**绝不把文字烧进生成图** |
| 源图形（logo/图标/徽标） | 精确矢量 / 确定性重绘 | **绝不用「只是像」的图形**；分辨率不足 → 以裁切为参考**重建**同轮廓/比例/颜色的高分资产 |
| 数据图形 | 原生图表/表格，或精确裁切 | 每个值、标签、关系保留；**绝不生成式重造** |
| 简单精确几何 | 原生形状 | 仅当填充、描边、几何、层序都忠实 |
| 场景图（照片/人物/产品） | 图层 | 可参考编辑或按配准层重生成 |
| 不可读 / 不安全区域 | `manual_required` | **阻塞**，而不是编造文字、数值或替换物 |

**可见面权威**：保留每一处可读字符串、相对位置、裁切、z序、色彩关系；**绝不**「优化」版式、改写文案、替换品牌图形。

---

## 四 · 最小有用层栈

按页决定**能让目标对象独立的最小层栈**；**绝不为最大化层数而拆**。

典型自底向上：`base`（干净满幅背景，必要时重建隐藏像素）→ `midground` → `subject`（可独立移动的抠图）→ `foreground`（跨主体的特效/边框）→ `source-graphic`（精确标记+数据图形）→ 原生文字与形状。

- **配准组规则**：同组每层配准到同一规范页 bbox；保持画布/位置/缩放/姿态/光照/风格；**绝不裁掉满幅配准层**
- **批量非重叠对象**：共用隔离处理的对象让参考工具一次产出一张**层板**再按 bbox 拆分，不要每个对象单独一张
- **为最终分辨率重建**：插值补不回细节
- **是「参考编辑」不是「重新诠释」**：可修补隐藏像素，**绝不**重新设计场景、换人、加文字、改 logo

---

## 五 · 源证据

分层决策前写 `analysis/reconstruction_inventory.json`，**只记录可见事实**：页序、帧 bbox、SHA-256、可见区域（id、bbox、族、逐字文本、置信度）、充足度、遮挡、重叠观察。

**不写**最终层选择、提示、输出文件名。低置信文字、不确定边界、未识别图形 = **未决证据，阻塞交付**。

---

## 六 · 放行门

| 最终检查 | 必需证据 |
|---|---|
| 页面清单 | 每帧一页、顺序一致、同一画布 |
| 原生文字 | 每个可读字符串逐字存在且可编辑 |
| 源图形 | 身份与几何保留、分辨率足够；无替代品 |
| 数据图形 | 每个值与关系原生且已验证，或来自精确源资产 |
| 层配准 | 共享画布/位置，无跳变、缝隙、漂移 |
| 可见保真 | 主体身份、姿态、裁切、光照、z序保留 |
| 诚实重建 | AI 恢复的隐藏像素标注为「重建」 |
| 排除源页 | 规范整页源图**不**作为幻灯片媒体被引用 |

层漂移 → 从规范参考用更窄的编辑重试；**绝不**靠改原生文字或拍平页面补偿。路径耗尽 → 标记 `Needs-Manual` 并阻塞导出。
