# 风格族 3 · 水彩风

> 美学锚点：手稿本、植物图鉴、建筑水彩、Sargent 的速写。
> **本风格是 Rouo 自研体系**，没有上游骨架，依据本文件从零实现。
> 与其他四族的根本区别：**它靠"不精确"成立**。干净、整齐、边缘锐利——恰恰是它要避免的。

---

## 一 · 三要素：纸 · 颜料 · 水

水彩风不是"用柔和的颜色"，而是三个物理属性同时在场。**缺任何一个都会掉成"廉价渐变 PPT"**：

| 要素 | 物理表现 | 实现手段 |
|---|---|---|
| **纸** | 纹理、毛边、微微起伏、吸水的暖白 | 纸纹底图 + 极低透明噪点；**底色绝不用纯白 `#fff`** |
| **颜料** | 颗粒沉积、色域不均、边缘比中心深 | 多层低透明度叠加 + 颗粒噪点；一个色块要有 2–3 层才像颜料 |
| **水** | 水痕边（water bloom）、晕开的毛边、连接处的积水线 | 边缘位移扰动（不规则轮廓）+ 外圈淡晕环 |

> **判断做没做对的一句话**：把图放大到 200%，边缘应该是**毛的、有浓淡的**，不是矢量锐边。

## 二 · 五套颜料色板（只能选，不能自定义）

每套按**真实颜料**命名，用"颜料名 + 纸色"的组合，而不是 RGB 编号。

| # | 色板 | 气质 | 适合内容 | 主颜料 `--pig` | 次颜料 `--pig-2` | 纸 `--paper` |
|---|---|---|---|---|---|---|
| 1 | 🪵 **靛青与赭石** | 温厚、有尘土气、最通用 | 人文 / 历史 / 旅行 / 手作 / 通识 | `#2f4a63` 靛青 | `#b07d46` 赭石 | `#f6f1e6` |
| 2 | 🌹 **玫瑰茜草** | 柔、一点点甜、不幼稚 | 生活方式 / 心理 / 教育 / 女性向 / 品牌故事 | `#a55a68` 茜草红 | `#6d7f63` 灰绿 | `#f8f3ee` |
| 3 | 🌿 **苔绿与石灰** | 安静、自然、清醒 | 自然 / 可持续 / 健康 / 农业 / 环保 | `#5f7a52` 苔绿 | `#8a8577` 石灰 | `#f5f3e9` |
| 4 | 🌌 **普鲁士蓝** | 冷、深、有一点忧郁的理性 | 科学 / 建筑 / 海洋 / 心理 / 深度长文 | `#1f3a5f` 普鲁士蓝 | `#c2843c` 熟赭 | `#f2f3f0` |
| 5 | 🍎 **石榴红** | 暖、有食欲、有生命力 | 餐饮 / 节庆 / 儿童 / 市集 / 品牌发布 | `#a8332c` 石榴红 | `#3f6b5c` 松绿 | `#f7f0e4` |

**色板变量**（替换骨架/项目里的这 6 行）：

```css
--pig:       #2f4a63;   /* 主颜料：标题、关键块、强调 */
--pig-rgb:   47,74,99;
--pig-2:     #b07d46;   /* 次颜料：只做点缀与对比，占比 ≤ 主颜料 1/4 */
--pig-2-rgb: 176,125,70;
--paper:     #f6f1e6;   /* 纸色：暖白，绝不用 #fff */
--paper-rgb: 246,241,230;
```

**硬规则**：
- 一份 deck 只一套色板，**不混搭**
- 一页最多 **2 种颜料**（主 + 点缀），第三色只在图表里作为分类色出现
- **暗色不用"颜料+黑"实现**，用"同色相加深 + 提高饱和度"（颜料越浓越深，不是越黑）
- 不接受用户给的任意 hex —— 委婉拒绝并展示五套

### 颜料深色阶（替代纯黑）

文字和深色块**不用 `#000` / `#111`**，用压实后的颜料：

```css
--ink-soft:  #241f1a;   /* 中性深（文字主色） */
--ink-pig:   #1d3040;   /* 主颜料压实版（靛青系） */
```

纯黑在纸上是"印上去的"，颜料深色才是"画上去的"。这一条直接决定成品质感。

## 三 · 字体

**衬线打底，等宽做注，不用无衬线大标题。**

| 角色 | 字体 | 用法 |
|---|---|---|
| 中文标题 | **Noto Serif SC** 400–500（**不要 700/900**） | 水彩要"轻"，粗黑体一压就成海报了 |
| 中文正文 | Noto Serif SC 300–400 | 与纸的质感一致 |
| 拉丁标题 | **Georgia** italic / 400 | 本机无 Playfair，Georgia 是正确落点 |
| 拉丁正文 | Georgia 400 | |
| 注 / 手写批注感 | 等宽 + 斜体（Consolas italic） | 模拟铅笔标注 |

**三条排版纪律**：
- **字重上限 500**。水彩风的重量来自颜料，不来自笔画
- 标题**允许两行甚至三行**（不像电子风要求 nowrap），斜向留白是它的呼吸方式
- **不要在文字下加色块底**。要让文字"躺在纸上"，不是"贴在色块上"

### ⚠️ 本机字体现实

本机无手写体。**不要声称使用手写字体**，用 `Georgia italic` + `Consolas italic` 表达"手写批注感"即可。要真手写体，需用户提供字体文件并 `@font-face` 本地引入。

## 四 · 版式语法：贴着纸摆，不画框

水彩风的布局是**七条语法**，与极简风的网格逻辑完全相反：

1. **留白 ≥ 40%**，且是**不规则留白**（不是居中对称的均匀留白）
2. **元素不贴齐网格** —— 允许 ±1–2% 的视觉偏移，让它像"手放的"
3. **分隔靠留白，不靠线**。需要硬分隔时用**一条手绘感的淡笔触**，`opacity .25`，两端渐隐
4. **不用卡片**。要区分区块，用**淡色晕染底**（blob）而不是圆角矩形
5. **文字必须在"干净区"** —— 颜料只出现在文字块外围或背后很淡处，任何笔触不得穿过文字
6. **一页只有一个视觉主角**（一朵晕染 / 一张图片 / 一个大数字），其余全是配角
7. **边缘装饰可出血**：晕染块允许超出画布边界，这是水彩的"溢出感"

### 版式骨架（五种，够用）

| 版式 | 结构 | 用途 |
|---|---|---|
| W1 封面晕染 | 中央或偏下大面积晕染 + 标题压在干净区 | 第 1 页 |
| W2 左字右染 | 左 60% 文字 / 右 40% 晕染或图片 | 正文主力款 |
| W3 单一大数字 | 数字用颜料色大字号 + 手绘下划线 | 抛数据 |
| W4 图鉴网格 | 2×3 或 3×2 图片 + 下方手写感 caption | 植物图鉴 / 作品集 / 对比 |
| W5 引语散页 | 整页纸 + 一句居中引语 + 一朵角落淡晕 | 收尾 / 章节过渡 |

**叙事节奏**：水彩风**不要明暗交替**（那是电子风的规则）。节奏靠**颜料的浓淡**——浓页（大面积晕染）/ 淡页（几乎纯纸）/ 极淡页（只有一条笔触）交替。

## 五 · 技术实现

### 5.1 网页 deck：SVG 滤镜

水彩的核心是**边缘位移**。用 feTurbulence + feDisplacementMap 把规整的几何形状"揉"出毛边：

```html
<svg width="0" height="0" style="position:absolute">
  <filter id="wc-edge">
    <!-- 噪声 → 位移 → 毛边；baseFrequency 越小边缘越"大团"，numOctaves 越高越细碎 -->
    <feTurbulence type="fractalNoise" baseFrequency="0.022" numOctaves="3" seed="7" result="n"/>
    <feDisplacementMap in="SourceGraphic" in2="n" scale="26" xChannelSelector="R" yChannelSelector="G"/>
  </filter>
  <filter id="wc-grain">
    <!-- 颜料颗粒沉积 -->
    <feTurbulence type="fractalNoise" baseFrequency="0.9" numOctaves="4" result="g"/>
    <feColorMatrix in="g" type="saturate" values="0"/>
    <feComponentTransfer><feFuncA type="linear" slope="0.13"/></feComponentTransfer>
    <feComposite operator="in" in2="SourceGraphic"/>
  </filter>
</svg>

<!-- 用法：一个晕染块 = 3 层同形状、不同缩放与透明度 -->
<div class="wash">
  <svg viewBox="0 0 600 400" preserveAspectRatio="none">
    <ellipse cx="300" cy="200" rx="260" ry="170" filter="url(#wc-edge)" fill="var(--pig)" opacity=".14"/>
    <ellipse cx="310" cy="195" rx="200" ry="130" filter="url(#wc-edge)" fill="var(--pig)" opacity=".18"/>
    <ellipse cx="295" cy="205" rx="130" ry="86"  filter="url(#wc-edge)" fill="var(--pig)" opacity=".26"/>
    <rect x="0" y="0" width="600" height="400" filter="url(#wc-grain)" fill="var(--pig)" opacity=".22"/>
  </svg>
</div>
```

**三层原理**（照抄这个比例，不要凭感觉）：
- 外层 `opacity .12–.16` / 尺寸 100%
- 中层 `.16–.20` / 尺寸 78%
- 内层 `.24–.28` / 尺寸 52%
- → 叠加后中心浓、边缘淡，这正是颜料沉积的样子

**水痕边**（关键细节）：在内层外侧再画一个 `fill:none; stroke:var(--pig); stroke-width:1.5; opacity:.18` 的同形轮廓，`filter` 用同一个 —— 就是那圈"水退后的边"。

**纸纹**（全页底）：一个覆盖全页的 `feTurbulence` 灰噪点，`opacity .04–.06`。**超过 .08 就显脏。**

**性能红线**：`feDisplacementMap` 很贵。
- 一页最多 **3 个** filter 实例
- `viewBox` 尺寸不要超过实际渲染尺寸的 1.5 倍
- 晕染块做静态（**不要跟鼠标联动动画**），入场动效只做 `opacity 0→1`
- 低功耗模式 / 打印导出时**冻结 filter 结果**（导出为 PNG），别让浏览器实时算

### 5.2 原生 PPTX（手作线 SVG→PPTX）：必须烘图

> **完整做法、实测数字与六个坑 → `27-pptx-assembly.md`**（含可复用装配器 `scripts/pptx_assembly.py`）。
> 下面只留原则。

**DrawingML 没有滤镜。** `feTurbulence` / `feDisplacementMap` 转到 PPTX 会全部丢失或栅格化成巨图。

正确做法分两类：

| 元素 | 做法 | 原因 |
|---|---|---|
| **晕染块 / 纸纹底** | 先在浏览器渲染好 → **导出透明 PNG（2–3 倍分辨率）→ 作为图片插入** | 保住质感；且这些是纯装饰，不需要可编辑 |
| **文字、数字、标题** | **保持原生文本框**（铁律 3） | 必须可改 |
| **颜料色的几何块**（色带、色底） | 用**手写不规则 freeform 路径**（贝塞尔微扰），不用滤镜 | 原生形状仍可编辑，且不规则度可控 |
| **一条手绘感笔触** | 原生 freeform 路径 + 两端渐隐（渐变填充的 alpha 从 0→1→0） | |

**导出参数**：PNG 用 `@2x` 或 `@3x`（1600px 宽的晕染块 → 输出 3200/4800px），带 alpha，PNG-24。JPEG 会把毛边的柔化变成块噪。

**图层顺序（不能错）**：
```
纸纹底（满版 PNG）
  → 晕染块 PNG（可多个）
    → 颜料色 freeform 形状
      → 原生文本框 / 数字          ← 文字永远在最上层，且下方必须是干净区
        → 手绘笔触（少量，压在文字下或旁）
```

### 5.3 量产线（COM 直驱）：❌ 不支持

WPS / PowerPoint 的 COM 接口**无法生成不规则毛边、无法做颜料沉积**。硬要走量产线只会得到"直角色块 + 柔和配色的普通 PPT"，那不是水彩风。

**能力边界必须提前告知**：水彩风走**网页 deck** 或**手作线 SVG→PPTX**，**不走量产线**。

## 六 · 硬规则与禁区

### 必须

1. 边缘是**毛的**（放大 200% 看不出一条锐利的矢量边）
2. 一个色块有 **2–3 层叠加**，中心浓边缘淡
3. 纸色**不是纯白**，文字深色**不是纯黑**
4. 留白 ≥ 40%，且**不规则**
5. 一页**最多 2 种颜料**
6. 文字所在区域**干净**，笔画不穿过文字
7. 字重 **≤ 500**

### 禁止

- ❌ **数字感渐变** —— `linear-gradient` 从一个色到另一个色的平滑过渡，是水彩的**头号杀手**。晕染必须是不规则形状的叠加，不是线性渐变
- ❌ **锐利几何边** —— 直角矩形、精确圆形、1px 硬描边
- ❌ **圆角卡片 + 阴影** —— 那是 SaaS 语言，和水彩无关
- ❌ **荧光色 / 高饱和霓虹**（那是电子风与极简风的工具）
- ❌ **第三、第四种颜料铺满**
- ❌ **粗黑体大标题**（≥ 600 字重）
- ❌ **emoji**
- ❌ **颜料穿过正文文字**
- ❌ **纹理 opacity > .08**（会显脏，像扫描件没清理）

> **AI 生成水彩最常见的失败**：糊成一团没有构图的色斑。**颜料是氛围，构图的骨架还是清晰的对齐与层级。** 先按普通排版把信息层级做对，再把颜料垫到底下。

## 七 · 交付前必查

1. 放大 200%，**边缘是毛的**
2. 每个晕染块**至少 3 层**，中心浓边缘淡
3. 有**水痕边**（内层外侧那圈淡描边）
4. 纸色非纯白、文字深色非纯黑
5. 留白 ≥ 40% 且不规则
6. 一页 ≤ 2 种颜料
7. **文字区域干净**，颜料没穿字
8. 字重 ≤ 500，无粗黑体大标题
9. **没有 `linear-gradient` 做晕染**
10. 纸纹 `opacity ≤ .08`
11. 每页 filter 实例 ≤ 3
12. 有低功耗 / 静态冻结方案（filter 结果可烘成 PNG）
13. 走 PPTX 时：晕染是烘好的 PNG，**文字是原生文本框**，图层顺序正确
14. 没有 emoji

## 八 · 能力边界

| 交付格式 | 支持 | 说明 |
|---|---|---|
| **网页 deck** | ✅ **推荐** | SVG 滤镜原生支持，质感最完整；横滑翻页与演讲者模式照用 |
| **原生 PPTX（手作线）** | ✅ 需烘图 | 晕染导出透明 PNG 插入，文字保持原生可编辑；**滤镜质感会固定为位图**（不能再调参数） |
| **原生 PPTX（量产线 COM）** | ❌ | 无法生成毛边与颜料沉积，不要承诺 |
| **PDF** | ✅ | 网页 deck 打印或 PPTX 导出，静态渲染无损失 |
| **MP4** | ⚠️ | 录屏或转 PPTX 后导出；水彩风本身动态需求低，静止画面即成立 |
| **数据密集页** | ❌ 不擅长 | 图表与表格要清晰锐利，与水彩质感冲突。数据页多于 1/3 时**换极简风** |
