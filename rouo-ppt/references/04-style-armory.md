# 风格武库 · PPT 二十式 + 色彩推导协议

> 方向门「秒数轮盘」的弹药库。基于对全球 10 大演示类型各 top5 公认最佳设计（共 50+ 真实案例）的调研反推。
> ⚖️ **定位**：这是「没思路时翻的弹药」，不是「必须从这里选」的清单。用户给了内容/品牌/参考，设计就从那里展开。武库的职责是帮用户规避最差，不是规定好设计长什么样。

## 用法

1. **温度体系**：每种标了 `大胆 / 中性 / 安静`。**故意让大胆款占多数**——模型的确定性偏差天然偏安静极简，配比要把它往大胆推。
   - 方向 A（稳妥底盘）从安静/中性里按需求选；方向 B 取不同温度拉反差；**方向 C 由轮盘强制注入大胆款**。
   - ❌ 三个方向不要都落在「米白 + 留白 + 一个点缀色」——那是最常见的失败模式。
2. **还原度**：≥90% 闭眼做；70–90% 主体可做、个别细节降级；<70% 必须**标注哪部分用纯色块降级**，不假装能做出原版质感。
3. **字体**：给的是开源替代（Inter / Manrope / Space Grotesk / Fraunces / Newsreader 等），不写付费字体。
4. **hex 与字体都是示例锚点，不是配方**——用任何风格前先走下面的色彩推导协议。

## 色彩推导协议（用任何风格前先走这三步）

> ⚠️ 条目里的 hex 是示例锚点。同一风格用于不同内容，应推导出不同色值——直接复制条目 hex，只是在生产品味更好的平庸产物。写死配方让 100 个用户拿到 100 份同色产出，色彩的信息量归零。

### 三步法：采样 → 收敛 → 论证

| 步骤 | 做什么 | 为什么 |
|------|--------|--------|
| **1. 采样** | 主色从三个来源取，不凭空发明：① 品牌资产（logo/VI 直接吸色）② 内容真图（产品截图/摄影素材的主导色）③ 文化语境（内容主题自带的色彩记忆） | 凭空选色 = 从模型先验里抽签，抽出来的永远是那几个网红色；从内容里采的色天然带「为什么」 |
| **2. 收敛** | 用 oklch 把调色板压到 **2-3 个有彩色 + 1 组中性色**。中性色写成明度序列（L 0.15/0.35/0.65/0.92/0.98），有彩色之间拉开色相角 ≥60° 或明度差 ≥0.3 | 色多必乱；oklch 的 L 通道感知均匀，明度序列写出来就是层级系统 |
| **3. 论证** | 一句话写出「为什么是这个色」，写进产出注释或交付说明。例：「主色取自用户 logo 的赭石，压低 chroma 到 0.08 模拟油墨」 | **写不出这句话 = 在抄配方。** 论证是防平庸的自检门 |

### 印刷色质感：为什么低饱和比纯屏幕色高级

油墨印在纸上永远达不到屏幕 RGB 的最大饱和——人眼几十年被印刷品训练出的「高级感」本质是这层物理灰度。屏幕设计里刻意压 chroma = 借用印刷的质感记忆。

| 用途 | oklch chroma 参考 | 效果 |
|------|------------------|------|
| 大面积底色 | 0.01–0.04 | 纸感、不刺眼 |
| 品牌主色/强调 | 0.08–0.15 | 油墨感，醒目但不塑料 |
| 小面积点睛 | 0.15–0.22 | 保留活力，仅限小面积 |
| >0.25 满版铺 | 慎用 | 屏幕荧光感，只适合刻意「电子原生」的风格 |

### 文化语境速查：同一色相，不同语境

选色是选它背后的文化坐标。同是「红」，落点差之千里：

| 色相 | 语境 A | 语境 B |
|------|--------|--------|
| 红 | 故宫朱红（偏橙带灰）→ 传统/庄重 | 可乐红（高饱和正红）→ 消费/兴奋 |
| 蓝 | 蓝染绀（深偏紫灰）→ 手工/沉静 | 科技蓝 #0066FF → SaaS/效率（模型最爱的默认蓝，用前先问是不是在抽签） |
| 绿 | 抹茶/苔绿（黄相低饱和）→ 自然/日式 | 荧光绿 → 终端/hacker |
| 黄 | 藤黄/芥末（带棕灰）→ 复古印刷 | 警示黄 → 醒目/玩味 |
| 白 | 奶油纸白 #F5F0E8 → 出版物/暖 | 纯白 → 实验室/瑞士 |

## PPT 风格库（二十式）

### 大胆派（八式）

**1 · 新瑞士大字报 / Neo-Swiss Billboard** `大胆 · 还原98%`
- 参照：Scribe、Flock Safety 等 AI/SaaS 路演 deck 的大字流派；Bloomberg Businessweek 信息图
- 适配：融资路演、业务回顾、年度趋势复盘、产品发布关键页
- DNA：纯白或近黑底 + 单一高饱和强调色（电光蓝/荧光绿/品牌橙）+ 中性网格线。超大粗体无衬线标题占半屏，数字 tabular-nums 收紧字距。母版：大色块章节页一个词 / 巨型数字占半屏 + 小注 / 左右分栏对比 / 全幅扁平图表。零插画零 3D
- 实现：超大数字 `clamp()`；严格网格 CSS Grid；折线柱状用内联 SVG（比贴图锐利）

**2 · 黑底巨型数字剧场 / Black Big-Number Stage** `大胆 · 还原97%`
- 参照：Steve Jobs 2007 Keynote、小米发布会、Spotify Wrapped、Presentation Zen
- 适配：产品发布主题演讲、思想演示、全员大会、情绪向年度回顾
- DNA：纯黑底 + 纯白字高反差，一页只一个品牌强调色高亮。几何无衬线粗体，一屏一词或一个超大数字占满视野，大量负空间。母版：黑底居中一行大字 / 巨型数字+单位+一行注 / 左右参数对比双栏 / slogan 单页
- 实现：黑底白字几行 CSS；巨型数字 `clamp()`+flex 居中；左右对比 Grid 两列 + 条形高亮

**3 · 高饱和单色撞色海报 / Mono-Brand Type-as-Hero** `大胆 · 还原96%`
- 参照：Spotify Wrapped 视觉系统、Mailchimp 品牌书（Collins）、Netflix 红黑
- 适配：品牌/营销策略、campaign 宣讲、活动主视觉
- DNA：单一品牌主色满版铺底 + 黑或白反差字，撞色两层。超大字体即主视觉（type-as-hero）顶天立地。母版：满色块底反白巨字 / 双色块分割 / 巨型数字撑满
- 实现：满版 background-color；字体当图靠 font-weight 900 + 负字距。纯色块零素材

**4 · 全幅渐变宣言 / Full-Bleed Gradient Manifesto** `大胆 · 还原82%`
- 参照：Zuora『Tell a Different Story』销售 deck、Nike 宣言、国家地理跨页
- 适配：销售提案愿景页、品牌宣言、keynote 转折页
- DNA：满版渐变（暖橙→品红/深蓝→青）+ 反白宣言大字 + hashtag 口号。厚重无衬线全大写标语横贯。母版：满幅渐变居中反白宣言 / 应许之地愿景页 / 客户 logo 墙
- 实现：linear/radial-gradient 满版（纯 CSS 渐变是允许的）；logo 墙 Grid 灰度占位。原靠纪实大照片的部分降级为渐变铺底 + 大字（降约15%）

**5 · 糖果舞台课件 / Candy-Color Lecture Stage** `大胆 · 还原94%`
- 参照：Harvard CS50、高桥流、Presentation Zen
- 适配：教育课件、技术讲座、概念解释、代码教学
- DNA：深黑底 + 高饱和糖果色大字轮换（品红/青/明黄/绿）。无衬线超大字漂浮居中，一屏一概念，文字极少。母版：深黑底单个糖果色大词 / 等宽代码块语法高亮 / 舞台聚光感大字
- 实现：深黑底 + 单色超大字居中；代码块 pre + 等宽 + span 上色；聚光感用极淡 radial-gradient 暗角

**6 · 玩味圆润极简 / Playful Editorial** `大胆 · 还原75%`
- 参照：Mailchimp 品牌书、New Yorker 气质、Cooper 圆润衬线
- 适配：有态度的品牌 deck、创意机构提案、反极简的营销页
- DNA：荧光黄大面积 + 黑 + 少量撞色，反 SaaS 极简。圆润衬线大标题 + 杂志式留白编排。母版：荧光黄满底怪诞标题 / 不规则留白排版 / 大字玩梗文案
- 实现：手绘插画核心元素无生图做不了，降级为几何色块 + emoji + 旋转文字块（降约20%）

**7 · 不羁玩梗流行版 / Irreverent Pop** `大胆 · 还原80%`
- 参照：Reddit Ads 销售 deck、David Carson 式不羁排版、90s web 复古
- 适配：Z 世代品牌、玩梗营销、社区/创作者向、敢不正经的提案
- DNA：橙红 + 撞色，90s 复古色。混排 / 打破网格，玩梗口语文案。母版：fun 页玩梗大字 → facts 页节奏转折严肃数据
- 实现：故意打破网格用 transform 旋转/重叠/混合字号；复古质感用粗黑边 + 硬阴影（无 blur）；meme 插画降级为 emoji + 几何拼贴

**8 · Y2K 膨胀大字 / Maximalist 3D-Type** `大胆 · 还原78%`
- 参照：Spotify Wrapped 2022+、Memphis 撞色、Y2K
- 适配：年度回顾（情绪出圈向）、个性化数据卡、社交分享竖屏卡
- DNA：高饱和撞色满版（品红+青+橙）+ duotone 双色渐变。顶天立地巨型数字，年份做 3D 膨胀/金属质感。母版：撞色满版巨型膨胀数字 / duotone 底反白大字 / 竖屏可分享卡
- 实现：3D 膨胀用多层 text-shadow + perspective（非真 3D 渲染）；duotone 用 mix-blend-mode；金属质感降级为渐变填充文字（降约15%）

### 中性派（六式）

**9 · Bento 便当格 / Bento Grid** `中性 · 还原95%`
- 参照：Apple Keynote Bento 时代、新一代咨询 Bento/Big-Type deck、Stripe 年报指标卡
- 适配：产品功能汇总、咨询/QBR 数据汇报、销售成果页、指标页
- DNA：浅灰/奶白底或近黑底 + 品牌主色 + 1-2 强调色，卡片浅色分区 + 圆角 + 微描边。超大 display 标题 + KPI 数字 tabular。母版：巨型单句标题页 / 2×2、3 列**不等高**卡片每卡一洞见（数字/线性icon/sparkline）/ one-insight 超大数字页
- 实现：Grid `grid-template-areas` 做不等高；sparkline 内联 SVG；线性 icon inline SVG stroke

**10 · 暗色终端美学 / Dark Hairline Terminal** `中性 · 还原94%`
- 参照：Linear pitch deck、Vercel 设计语言、CS50 深黑课件
- 适配：开发者工具/技术产品发布、技术路演、工程汇报
- DNA：近黑底（#0D0D0F，**不是** #0D1117 深蓝）+ 1px hairline 细线网格 + 单一紫蓝强调。Inter Tight 大标题 + JetBrains Mono 做标签/数据。母版：极简标题页一句话 + mono 小标 / hairline 分隔的数据网格 / mono 标签特性列表
- 实现：border:1px solid hairline 网格；微光用极淡 box-shadow 而非真光效。**注意避开深蓝+霓虹禁区**

**11 · 双字体咨询版 / Two-Font Consulting** `中性 · 还原90%`
- 参照：McKinsey 2019 品牌系统（衬线+无衬线并置）、BCG 高管视角
- 适配：咨询报告、高管汇报、行业研究、权威机构提案
- DNA：深蓝 × 白二元 + 单一品牌色高亮（BCG 绿系），暖灰底呼吸感。**有性格的衬线大标题与无衬线正文高对比并置**。母版：左上角结论式 action-title / 蓝色细线 pattern / 杂志式左右分工 / 大数字 data-point 卡
- 实现：双字体并置；细线 pattern 用 repeating-linear-gradient；data-point 卡纯 CSS

**12 · 图谱箭头企业版 / Diagram-Driven Isotype** `中性 · 还原88%`
- 参照：Salesforce 销售 deck、Isotype 谱系、《Say It With Charts》、Gapminder
- 适配：平台/架构讲解、客户旅程、流程方法论、生态地图
- DNA：企业蓝色块 + 产品线分色 + 图标化能力网格。清晰无衬线。母版：横向客户旅程箭头流 / 分层平台架构图 / 图标化能力网格 / 2×2 瀑布金字塔结构图。**流程即叙事**
- 实现：箭头用 Flexbox + clip-path 三角或 SVG arrow；架构分层嵌套带边框 div；图标统一描边 inline SVG

**13 · 单图母图概念图解 / Diagrammatic Minimalism** `中性 · 还原95%`
- 参照：Simon Sinek 黄金圆环 TED、Bauhaus 几何抽象
- 适配：理论框架讲解、TED 式思想传播、模型/方法论可视化
- DNA：极简白/浅底 + 黑 + 1 个强调色，几何纯色。**唯一几何母图（同心圆/三角/矩阵）承载全部概念**，标签大写嵌入图形，一图定全场
- 实现：同心圆 border-radius:50% 嵌套或 SVG；三角 clip-path；标签 absolute 定位贴图上。纯几何完美还原

**14 · 波形叙事 / Narrative Sparkline** `中性 · 还原91%`
- 参照：Nancy Duarte《Resonate》叙事图谱、Al Gore 气候演讲
- 适配：演讲结构设计、变革叙事、before/after 对照、数据故事弧线
- DNA：深底或白底 + 品牌橙强调转折点 + 灰化对照。**横贯全屏的振荡波形线**，波形上 text 标注点，上下并置对照波形，逐步 reveal
- 实现：波形用内联 SVG path（平滑贝塞尔）；标注点 SVG circle+text；reveal 用 stroke-dashoffset 动画

## 有生图能力时的提示词心法

Mood, Not Layout——生图提示词写「氛围与材质」，不写「版式与布局」。版式由 HTML/SVG 控制，生图只负责插画与照片质感。默认（未确认用户有生图能力）不可选生图专属风格。
