# 页面工艺 · 手写 SVG 执行标准 + 技术契约

> 手作线阶段 D 的核心参考，执笔前必读。两部分：**工艺**（怎么当好每一页的作者）与**契约**（SVG 的技术边界）。

---

# 第一部分 · 工艺

## 一 · 每页动笔前的固定动作

```
1. 重读 <project>/design-lock.md     ← 强制，每页一次
2. 查该页的 rhythm（anchor/dense/breathing）
3. 查该页的版式继承 / 图表引用
4. 确认该页的 page job（这一页为读者做什么）
5. 动笔
```

**所有色彩/字体/图标/图片必须从锁里来**——不得凭记忆或临场发明。
⚠️ 空/缺失的条目是立约时的**刻意信号**，不要去「补全」它。

## 二 · 三条不可违反的约束

1. **SVG 必须手写，禁止脚本生成。** 遍历页面列表批量模板化、从数据 emit、任何形式的 generator 都禁止。借口清单（省 token / 快速草稿 / 用户着急）**全部无效**。原因：跨页视觉一致性依赖**带着完整上游上下文逐页作者化**，脚本做不到——这条路径在实测中被尝试过并放弃了。
2. **顺序生成，禁止分批。** 全局设计上下文确认后逐页连续生成，「先做 5 页」式的分组禁止。
3. **严禁子代理生成 SVG。** 页面生成是上下文依赖的，必须由当前主 agent 端到端完成。

## 三 · 每页的固定交付要件

### 页面角色（page job）

| 角色 | 它为读者做什么 |
|---|---|
| hero | 立住这一屏的唯一观点 |
| 过渡 | 把上一段带到下一段 |
| 数据 | 让一个数字或一组对比被读懂 |
| 引语 | 用别人的话增强说服力 |
| 拆解 | 把复杂物拆成可理解的部件 |
| 结论 | 收敛全篇，给出方向 |
| 结尾 | 致谢 / 联系 |

**判断标准**：角色说不清，形式必然发散。

### 观众距离（最常被做错的地方）

| 距离 | 字号 |
|---|---|
| 10cm 手机 | 正文 ≥14px |
| 1m 笔记本 | 正文 ≥16px |
| **10m 投屏 / 教室** | **正文 ≥24px，标题 60–120px** |

⚠️ 用笔记本的距离做投屏的 deck，后排一定看不清。

### 容量验算

动笔前画 **3 个 5 秒 thumbnail**，算内容塞得下吗。防溢出、防挤压。

## 四 · 页面载体菜单（device menu）

不要每页都用「圆角卡片 + 标题 + 三条 bullet」。日常载体：

| 载体 | 什么时候用 |
|---|---|
| card | 并列的同级单元（≤4 个） |
| band | 横向分区，纵向堆叠 |
| icon-and-label | 一组并列的小概念 |
| KPI tile | 单个关键数字 |
| divider | 章节分隔 |
| quote block | 引语 |
| 表格 | 多维度精确对比 |
| 图表 | 趋势 / 分布 / 构成 / 关系 |
| 时间轴 | 演进 / 流程 |
| 结构图解 | 拆解 / 组成 |
| 全幅图像 | 情绪主导，信息在图上 |

⚠️ **打破「每页都是卡片网格」的默认惰性**——同一份 deck 至少 3 种不同载体。

## 五 · 视觉母题的一致性

一份 deck 应有一个**贯穿的视觉母题**，在不同页以不同方式出现。母题从内容里长出来（定向阶段推导）。**判断成功**：缩略图排成一墙，一眼看出属于同一份文件，但每页不重复。

## 六 · 数据页处理

- 图表必须由**真实数据现算**，不手绘不估算
- 每个数据页有**出处牌**：`SOURCE <来源>` / `N <样本量>` / `UNIT <单位>`
- ⚠️ **页脚带高度由出处牌决定，不是正文**。实测：出处牌 3 行约 101–113px。**排 deck 先算页脚安全底线，再倒推每页内容高度**，否则最后几页必然压字。

## 七 · 排印细节

- 引号用「」；数字 `tabular-nums`（对齐数据列尤其）；中英混排留一个空格
- display 字体不用 Inter/Roboto/Arial/system（品牌规范明确用除外）
- 本机可用：`Noto Sans SC` / `Noto Serif SC` / Consolas / Georgia / Segoe UI
- 数值/编号/微标签统一用一个等宽字体（如 Consolas + tabular-nums）

```css
text-wrap: pretty;                    /* 避免孤字 */
color: oklch(0.65 0.15 250);          /* 均匀色彩空间 */
display: grid; grid-template-columns: repeat(12, 1fr);
```

## 八 · 常见陷阱（实测踩过的）

| 陷阱 | 表现 | 怎么避 |
|---|---|---|
| **巨型字号换行** | 封面超大标题折行顶掉底部 | 验算单行宽度（字数×字号≤容器宽）+ `white-space:nowrap` |
| **绝对定位标签互压** | 双元素叠放时窄端挤压 | 按**最长文本**估宽，不按平均值 |
| **后代选择器漏进子块** | `.nps b{font-size:196px}` 把公式里的 `<b>` 也放大 | 巨型字号规则一律写 `.nps > b` |
| **页脚压字** | 最后几页内容盖住页脚 | 先算页脚安全底线再倒推内容高度 |
| **多页截图分不清边界** | 同色背景两页看不出分界 | 页间加 1–2px 分隔线 |
| **双页码打架** | 单页自带页码 + 外壳也有 | **单页内容绝不自带页码** |
| **安静派做过头** | 大片死白+微缩字号 | 留白是构图，首屏必须有视觉锚点 |

## 九 · 门点质检节奏

```
P01–P05 → 早期门 → 剩余页 → 终门     （计划页数 ≤6 时跳过早期门）
```

- 只由两种事件触发：**覆盖页均已存在的门点**、**一次整合修复的结束**。之外跑质检 = 节奏违规
- 早期门除报问题外还验证**方法论**——修改前输出一行：
  `gate-signal: method=<被解析的规则，或 none> | page-local=<计数> | not-exercised=<列表>`

## 十 · 修复纪律

**在拥有故障的最浅层修复**：页面局部问题修那一页；清单/规格/资源问题修立约产物；工具失败修源头产物。从路线声明的指针处恢复。**不要静默降级必需产物。**

# 第二部分 · SVG 技术契约

## 十一 · XML 有效性（一个字符就能废掉整个文件）

SVG 是严格 XML。两条规则：

| 字符类别 | 必须 | 禁止 |
|---|---|---|
| 排印符号（— © ® → · NBSP 全角标点 emoji…） | **写原始 Unicode**：直接写 `—` `©` `→` | HTML 命名实体：`&mdash;` `&nbsp;` `&hellip;` |
| XML 保留字符（`&` `<` `>` `"` `'`） | **只用 XML 实体**：`&amp;` `&lt;` `&gt;`（如 `R&amp;D`） | 裸 `&` `<` `>` |

## 十二 · 结构黑名单（全局禁止）

`mask` · `<style>` · `class` · 外部 CSS · `<foreignObject>` · `textPath` · `@font-face` · `<animate*>` / `<set>` · `<script>` / 事件属性 · `<iframe>`

## 十三 · 内联视觉属性允许清单

内联 `style` 只可携带：
- **画法/线**：`fill`、`stroke`、`stroke-width`、`stroke-dasharray`、`stroke-linecap`、`stroke-linejoin`、`fill-opacity`、`stroke-opacity`
- **文字**：`font-family`、`font-size`、`font-weight`、`font-style`、`text-anchor`、`letter-spacing`
- **透明度与 defs 画法**：`opacity`、`stop-color`、`stop-opacity`

`filter`、`clip-path`、`marker-start/end` 是**直接属性**，永不写成内联 style。

**紧凑继承式编写**：公共排印属性放 `<svg>`（有可见文字就带 `font-family`）；共享排印/画法放最近的 `<g>`；根元素上禁止画法/效果；真子覆盖要显式写。**绝不用** class/样式表、编码载荷。

**颜色**：新实色用大写六位 `#RRGGBB`；`fill`/`stroke` 可用小写 `none` 或本地 `url(#id)`。

## 十四 · 字面几何语法

`x` `y` `width` `height` `rx` `cx` `cy` `r` `stroke-width` 写成 **viewBox 空间里的有限无单位十进制**（`x="120"`）。百分比、表达式、奇异数字拼写 = 错误；非法显式值**绝不**回退到默认。

## 十五 · 画布

- 用**已锁定的**画布 id 与精确 viewBox；所有页共享完全相同的 `viewBox="0 0 W H"`（正整数像素）；根 `<svg>` 的 transform **禁止**
- 快道（无锁）用第一张 SVG 建立画布，其后每页完全一致
- 导出在 `1 SVG px = 9,525 EMU` 处量化一次

## 十六 · 条件接口（用到才适用）

| 特性 | 契约要点 |
|---|---|
| 线端标记 `marker` | 引用 `<defs>` 里本地 `<marker>`，`orient="auto"`，唯一子元素是五种原生线端之一（三角/stealth/箭头/菱形/椭圆）；其它形状阻塞导出 |
| 图片裁切 `clip-path` | **只**在 `<image>` 上有原生映射；一个本地 `<clipPath>` 含恰好一个 circle/ellipse/rect/path/polygon；形状/组/文字上的 clip-path 禁止 |
| 同文档 `<use>` | `href="#id"` 指向 `<symbol>`（有限正 viewBox）或图元/`<g>`；复用子树不得带占位符/替换元数据 |

## 十七 · 页面契约与元素分组

**页面设计闭合**：最终页 SVG 包含该页**所有可见元素**（文字、图片、形状、图示、图表/表格、背景）；备注、动画、切换另行拥有，不属于页面契约。导出器**绝不**发明 SVG 里没有的可见内容。

**元素分组（强制）**：
- 每个可见的直属根 `<g>` 声明 `data-pptx-bounds="x y width height"`，大小是该模块预期区域；根组重叠 >1px **失败**
- 每个逻辑页面单元包进一个**描述性顶层 `<g id>`**（页面标题也是独立组）；id 页面唯一且描述性（如 `card-1`、`header`、`footer`）
- **禁止**：整页一个大 `<g>`；大量未分组根图元；每个小标记各一个顶层组；匿名顶层组

## 十八 · 共享美学底线（无更高权威时的默认）

技术契约是**绝对的**；更高权威（用户/品牌/已解析风格）能覆盖下列**默认**，不能覆盖技术边界：

| 关注点 | 默认 |
|---|---|
| 文字块节奏 | 段间距**明显大于**段内行距；同级块共用一套节奏 |
| 排印角色 | 用**最少**的语义文字角色保住层级；差异在缩略图尺度也可辨 |
| 观看距离 | **先**定交付场景与距离**再**定密度与字号；不够就重构/拆分，**绝不静默缩小** |
| 对比与编码 | 新造的区分**组合**明度/字重/尺度/形状/标签，**颜色不得单独承载必需区分** |
| 自然换行 | 在语义短语/标点处断行；末行自然变短；避免孤字行 |
| 内容场域 | 先立正文框再放模块；密集页用栏距/模块间距制造呼吸 |
| 对齐与邻近 | 从当前构图建立共享轴；相关元素比不相关更紧 |
| 边界强度 | 从间距/对齐、规线到描边、填充面板，按关系选强度 |
| 标题与页框 | 语义标题是构图的一部分，不是自动固定页眉带；页码只在承担导航时保留 |
