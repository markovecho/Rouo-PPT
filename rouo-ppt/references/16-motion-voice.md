## 一 · 硬依赖：演讲者备注

**音频以完整的分页备注为前提**：

- 手作线：先产 `notes/total.md`，再切分（`python "…/scripts/tools.py" notes-split <project>`）
- 原生编辑线：按输出页写 `notes/<svg-stem>.md`（绝不在往返工作区上跑切分器）
- **绝不**在备注缺失/不完整时进入音频生成

**备注只用口语散文**：TTS 逐字朗读——标题、项目符号、`[tag]`、时长行都会被念出来。每内容页 2–5 句自然句，封面/章节/结尾 1–2 句，整 deck 一种语言，来源限于该页内容——**备注绝不添加页面没有的断言**。

## 二 · 声音设计原则（双轨制，铁律）

动画音频**必须两层独立设计**：

| 层 | 作用 | 时间尺度 | 与视觉 | 频段 |
|---|---|---|---|---|
| **SFX（节拍层）** | 标记每个视觉 beat | 0.2–2 秒 | **强同步**（帧级） | 高频 800Hz+ |
| **BGM（氛围底）** | 情绪铺底 | 连续 20–60 秒 | 弱同步（段落级） | 中低频 <4kHz |

**只做 BGM 的动画是残废的**——观众会潜意识感到「画在动但没声音响应」。

**工程硬参数**：BGM 音量 `0.40–0.50`；SFX `1.00`；BGM 比 SFX peak **低 -6 至 -8 dB**；`amix normalize=0`（绝不用 1）。频段隔离：`lowpass=f=4000` 压 BGM、`highpass=f=800` 推 SFX。Fade：BGM 入 `0.3s`、出 `1.5s` 长尾。

## 三 · 旁白音频（TTS）

### Step 1 · 语言
中文选 `zh-CN`（默认）/ `zh-TW` / `zh-HK`。

### Step 2 · 音色

默认 **edge** 后端。列出候选选 **3–6 个**（覆盖性别），一句话描述每个：

- 咨询/金融 deck → 沉稳男声 `zh-CN-YunjianNeural` 或清晰女声 `zh-CN-XiaoxiaoNeural`
- 教学/产品 → 明亮女声 `zh-CN-XiaoyiNeural` 或年轻男声 `zh-CN-YunxiNeural`
- 发布/广播 → `zh-CN-YunyangNeural`
- 英文 → `en-US-GuyNeural` / `en-US-JennyNeural`

> **克隆音色快路径**：用户给了 `voice_id` → 跳过推荐，钉住该音色，只确认语速/嵌入/视频。

### Step 3 · 参数

- 语速：`+0%`；密集备注（每页 >4 长句）`-5%`；短促紧凑 `+5%`
- 是否重新导出嵌入音频的 PPTX：默认是
- 是否继续导出视频：默认原生编码（Windows PowerPoint 2016+ 可用时）

### Step 4 · 执行

```bash
# 1. 生成音频
python "…/scripts/tools.py" notes-audio <project> --voice <ShortName> --rate <rate>

# 2. 重新导出并嵌入（手作线附加 --quick-generate --with-notes）
python "…/scripts/tools.py" export <project> --recorded-narration audio \
  --narration-start-floor 0.8 --narration-padding 0.5

# 3. 可选：原生视频（经已装 PowerPoint）
python "…/scripts/tools.py" video <pptx> -o <raw.mp4>
```

**要点**：
- 音频生成有阻塞式备注预检；退出码 `2` = 回备注生成，**绝不用半截音频继续**
- 顺序执行不捆绑；缺依赖就修好重跑，**绝不吞错**
- **字幕永远是外部 SRT，绝不烧进画面**
- 实时放映录制是**显式手动交接**，不是自动兜底

## 四 · 动画（animations.json sidecar）

> 本节是 **PPTX 侧**的对象动画（`AddEffect` / `animations.json`）。
> 网页 deck 的 `data-animate` / `data-anim` 配方走 `30-motion-recipes.md`，**两者不要混用**。

**触发**：已存在 `<project>/animations.json`，或用户明确要求逐页/逐对象动效。

> 仅「deck 级切换 / 自动前进」无 sidecar → 不进入本阶段，直接用导出 flag（如 `-a auto`）。

### 流程

1. **读语义上下文**（简报/锁/备注），做内容优先的**分组审计**：
   - 一个组里塞了多个独立叙述单元 → 拆成描述性直属根兄弟
   - 一个单元散在多个组 → 合进一个直属根组
   - **硬规则——视觉等价**：重组只改对象边界，**保留每个可见像素、画法顺序、坐标、原生元数据**
   - **硬规则——结构边界**：绝不跨原生图表/占位符/预设的边界去拆合
2. **列出锚点**：`python "…/scripts/tools.py" anim-groups <project>`（幻灯片与组键的唯一来源）
3. **规划逐页与逐对象动效**：从意义选不从目录覆盖选；顺序沿阅读路径（框架性题签先于它框住的单元入场）
4. **编辑 `animations.json`**：**稀疏覆盖、引用真实目标**——只写受影响页、只写与默认不同的字段。禁止：写不存在的页；为复述默认而罗列每个组
5. **校验**：`python "…/scripts/tools.py" anim-validate <project>`——校验失败会**报错而非回退**，之后回到导出路径

## 五 · 视频交付的脚本契约

导出视频（或录制旁白）时，**先判脚本状态，再动手**——判错会把用户的逐字稿改掉。

| 材料 | 处置 |
|---|---|
| 普通源材料 / 粗稿转写 | **源材料**：可编辑、可删减、可重组 |
| 用户**明确标注**的最终稿 / 逐字稿 / 口播稿 | **每个字与顺序都不可改**，只在语义边界分段 |
| 作为 TTS 输入的 SRT（用户标为最终） | 保留 cue 文本；原时间码只作节奏证据，**新合成的时序才是权威** |
| 绑定既有录音的 SRT | 保留其文本与音频时序权威，**不要**重新生成 TTS |
| 已按页切好的最终脚本 | 保留用户给的页边界，除非用户允许重排 |

### 硬规则 · 「最终」必须显式

**只有当用户明确说这是最终稿 / 逐字 / 原话时，才冻结字词。**
ASR 输出、字幕、草稿转写**一律不得**被推断成逐字契约——这是最容易「好心办坏事」的地方。

### 落稿

页面队列定稿后、动笔之前，把**每页脚本**写到 `notes/total.md`：用 `# Slide <n>` 作标题、`---` 分隔，
每段保持逐字。它是**生产输入**，不是「替代设计简报的分镜」。

### 与分镜的衔接

- 时长、镜头运动、定格帧构图 → `33-video-storyboard.md`
- 音频打点要落在**视觉 beat**（元素到位那一帧），不是镜头切换上
- 一句旁白对应**一个视觉状态**，不是对应一个元素出现
