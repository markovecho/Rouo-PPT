## 二 · 步骤

### 1 · 准备源材料

| 输入 | 动作 |
|---|---|
| 只有主题、无支撑事实 | 先做主题研究，落一份 Markdown + facts 记录（采用过的 URL 只留在里面） |
| PDF / DOCX / PPTX / HTML / URL | 用工具调度器转 Markdown：`python "…/scripts/tools.py" source <file_or_URL>` |
| CSV / TSV | 当纯文本表直接读 |
| Markdown / 对话文本 | 直接读 |
| 位图页帧 | **不走快道**，走 `14-image-rebuild.md` |

### 2 · 一次性规划（只存上下文，不落文件）

把以下锚点**一次冻结**在当前上下文：

- 大纲与每页**一句核心信息**（页面队列）
- 画布与 viewBox；观看距离与阅读模式
- 排印计划（标题/正文/注释的稳定锚点）——**目标交付字体**，不是写作宿主字体
- 语义色角色（背景/主文字/次文字/主色/强调）各带一个具体锚点
- 每页密度判定（`anchor` / `dense` / `breathing`）
- deck 级形状语言与跨页母题
- 每页资源需求（图/图标/图表），**写 SVG 之前备齐**

### 3 · 备齐资源

- 图片放 `images/`，保留出处
- 图标走图标库（具名品牌用 simpleicons）
- 单文件 HTML 交付时 logo/图片 base64 内嵌
- **备齐再动笔**：每个资源必须终态

### 4 · 逐页手写 SVG

- 一次性读齐 `08-page-craft.md`、`09-shape-language.md`
- 顺序手写、无确认停顿：P01 校准视觉身份与封面表达；第一张内容页校准几何与载体
- 文件放 `<project>/svg_output/`，零填充命名；画布由第一张 SVG 固定，其余完全一致
- **绝不用脚本/子代理批量生成**（铁律）

### 5 · 一次终检 + 导出

```bash
python "…/scripts/tools.py" check <project> --quick-generate --canonical-authoring --stage final --json
python "…/scripts/tools.py" export <project> --quick-generate --with-notes
```

### 6 · 可选后处理

备注 → `16-motion-voice.md`；动效/音频同。

**失败处理**：修拥有故障的 SVG/资源 → 重跑终检 → 再导出。**绝不为省事去创建简报或锁。**

**交付后改稿**：快道没有 spec/lock 可更新——直接改拥有故障的 SVG（及复现该行的页）；插删移页先重编号文件、页脚、目录页码；整 deck 换色换字体手动替换 `svg_output/`。然后重跑终检 + 导出。
