# Rouo-PPT
Rouo PPT 是给 AI 智能体的演示文稿工作室：五族风格（电子 / 极简 / 水彩 / 编辑 / 蓝图）乘三条产线。手作线逐页手写 SVG，出原生可编辑 PPTX；量产线用 COM 直驱 WPS 或 PowerPoint，可见地逐页生成；网页线是单文件 HTML，带动态背景、演讲者模式、观众屏同步。
动笔前必问风格、主题色与交付格式。文字形状表格图表公式全是原生对象，双击即改；只用真实品牌资产，取不到就诚实降级；颜色从内容推导，不凭空发明。整套 34 份文档、10 个脚本与完整性守卫。

A presentation studio for AI agents — five visual style families crossed with three production lines.

Rouo PPT is a self-contained skill bundle: one SKILL.md, 34 reference documents, and 10 runnable scripts. It plugs into any agent that reads skill definitions, then walks you through a gated workflow — facts first, then style, then direction, then craft.

Five style families — Electronic (magazine × e-ink), Minimal (Swiss International), Watercolor, Editorial (book typography), Blueprint (engineering drawing). Before writing anything, the skill stops and asks you to choose a family, a theme color, and a delivery format. Style is a decision, never a default.

Three production lines

Handcrafted — direction gate → three real visual options → design brief and lock → page-by-page hand-written SVG → native editable PPTX.
Mass line — fact gathering → chart factory → page-data JSON → element-type routing → COM-driven WPS or PowerPoint, generated visibly so you watch it happen.
Web deck — a single HTML file with WebGL backgrounds, presenter mode, audience-screen sync, and rehearsal timing.
Built to be edited — Text, shapes, tables, charts and formulas stay native. Double-click and change the words. A deck stitched from screenshots is not a delivery.

Real assets only — If a brand name appears, its official logo is mandatory. When it can't be fetched, the skill degrades honestly rather than forging a shape.

Refuses to be boring — Colors are derived from brand assets and content, never invented. Purple gradients, emoji icons, and left-accent rounded cards are blacklisted.

Guarded — A fail-closed integrity check verifies the whole bundle: frontmatter, all 34 reference documents, all 10 assets and scripts, lineage cleanliness, reachable hosts, and reference citations.

Offline-first — Web-deck fonts fall back to a local stack, icons come from a reachable CDN, and every network dependency is documented so nothing silently times out.

Inside — 34 reference docs and 10 runnable scripts — SVG-to-PPTX assembly, a COM drive engine, template-background extraction, LaTeX-to-OMML native formulas, deck and speaker-notes validators — plus two runnable web-deck skeletons.

Built for decks that hold up: pitches, reports, courseware, case studies, and data-heavy decks produced in batches. Install by dropping the folder into your agent's skills directory, or point your agent at SKILL.md directly.
